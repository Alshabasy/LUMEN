# LUMEN usability check (5 minutes)

## Purpose

Observe whether a first-time visitor can compare two candidate sites and locate
an Earthset time using the current interface. Record what happens; do not coach
the participant or fill in results from memory.

## Setup

- Use the deployed site when available; otherwise write down the local URL and
  mark the session as local.
- Start from the landing page in a fresh browser tab.
- Have a timer and this result table ready. Ask the participant to think aloud.
- Do not explain navigation unless the participant asks; note any help given.

## Five-minute script

1. **0:00–0:30 — Consent and context.** Say: “I’m checking the interface, not
   you. Please tell me what you expect as you go. I may take notes on the time
   and clicks.”
2. **0:30–2:15 — Compare two sites.** Say: “Please compare two landing sites.
   Tell me when you think you have a useful comparison.” Start the timer when
   the participant begins. Record elapsed time, clicks/taps needed to reach a
   visible site comparison, the sites compared, and whether they noticed the
   flat-horizon disclosure.
3. **2:15–3:45 — Find Earthset.** Say: “For the selected site, tell me when
   Earthset happens next.” Start timing at the prompt. Record the event time
   they report, whether they used the jump control or event list, and whether
   the event fell within the generated window.
4. **3:45–4:30 — Confidence check.** Ask: “What do you think this result does
   and does not tell you?” Record the participant’s own words briefly.
5. **4:30–5:00 — Close.** Ask for one confusing element and one useful element.
   Thank them; do not correct their answers until after the session.
