# Decisions

| Date | Decision | Alternatives | Why | Owner |
|---|---|---|---|---|
| 2026-11-13 | Lean static v1; terrain deferred | Full terrain engine | Validate the geometry and ship a usable explorer within the build window | Amr |
| 2026-11-13 | Explicit `MOON_ME_DE440_ME421` frame | Generic `MOON_ME` alias | The loaded DE440 FK defines the explicit frame and prevents alias drift | Amr |
| 2026-11-13 | Fixture-backed validation, no live browser requests | Browser-side Horizons calls | Reproducibility and offline demo behavior | Amr |
| 2026-11-13 | Unverified candidate sites remain unavailable | Display guessed coordinates | The honesty contract forbids invented scientific inputs | Amr |
| 2026-11-13 | Precomputed screening window is 2027-01-01T00:00:00Z through 2027-03-02T00:00:00Z at 900 s | Previous 19-day 2026 window | Cover more than two lunar synodic cycles while retaining a fixed reproducible interval; SPK and lunar PCK coverage were inspected before generation. Future UTC conversion uses the latest known leap-second offset and Horizons notes UTC/TDB after 2027-01-01 uses the last known leap second. | Amr |
| 2026-11-13 | Compare Horizons RAD event markers with LUMEN center crossings using the measured target semidiameter as the geometric elevation cutoff | Compare default limb rise/set against center crossings | Align event definitions, retain the 120 s acceptance tolerance, and preserve the Horizons fixtures; this is a comparison setting, not a change to LUMEN events. | Amr |
| 2026-11-13 | Keep a dated, committed Horizons snapshot for API-failure display | Blank live panels or zero-valued substitutes | Give the live panels an honest offline state with explicit capture time and source; never represent the fixture as current telemetry. | Amr |
| 2026-11-13 | Replace the user-supplied Moon hero clip whose original source could not be verified with NASA SVS “The Moon’s Rotation”; remove unused icon sprite | Keep unverified media in the release | Every shipped visual asset now has a traceable source and usage note; art remains separate from geometry. | Amr |
| 2026-11-13 | Schedule-slip comparison uses user-selected UTC start dates and a fixed seven-day slice of each polar site's generated elevation series | Compare whole-window summaries as if they represented a selected date | Keep the impact scenario date-specific, reproducible, and bounded by available samples; clip continuous outages at the selected slice edges. | Amr |
| 2026-11-13 | Horizon sensitivity slider masks stored center elevations at a user-selected 0–5° threshold, with 0° matching generated four-decimal summary fractions | Treat the slider as terrain geometry or alter the validated base summary | Teach threshold sensitivity while keeping the result explicitly illustrative and terrain-free. | Amr |
