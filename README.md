# LUMEN — Lunar Landing Site Navigator

LUMEN is a static, data-driven screening tool for lunar landing-site planning.
It shows geometric Sun illumination and direct-to-Earth visibility from cited
lunar sites. Results are not landing approval, a communications guarantee, or
NASA guidance; terrain is not included in v1.

## Status

The project is being built as a validated vertical slice: SPICE-generated JSON
feeds a React explorer. No scientific result is shown until it is generated by
the SPICE pipeline and carries provenance.
